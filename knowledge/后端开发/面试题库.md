### 1. API 设计

#### Q001 · API 设计 · 状态：已分析
**题目**：京东不同域的数据为什么分散？上游数据如何接入？
**关联**：Agent 开发 Q004 使用接入后的数据执行规则。
**考什么**：能否把跨域数据接入讲到所有权与一致性。
**解题思路**：
1. 列出每个上游拥有的字段、标识、更新节奏和访问边界。
2. 说明如何对齐身份，再处理重复、乱序、缺失与回补。

**参考答案**：模拟接入时，招聘域维护申请，组织域维护岗位，两个系统各自对自己的字段负责。我会约定稳定的申请和岗位标识，为外部标识建立映射；首次同步先取快照并记录水位，后续按游标或事件消费增量。对同一记录按上游版本幂等更新，关联暂时缺失的记录留待回补。最后按域统计延迟和差异，通过对账发现漏数；候选人应补充真实项目采用的接入方式。
