## 共享题库

[行为面试](行为面试/面试题库.md) 供各岗位准备实习与项目复盘、AI 协作和职业发展类问题。练习时结合自己的经历，讲清楚做过的判断和验证结果。

[后端通用](后端开发/面试题库.md) 收录跨语言的 API 设计、数据库与事务、并发、缓存与分布式系统题。准备 Java 或 Python 后端面试时，可搭配相应的岗位库使用。

各库独立编号。跨库引用写明库名和题号，例如「后端通用 Q001」。
